# Simply U+ 가이드라인 (심플리하게)

원본 PDF는 **`Simply U+ 가이드라인.pdf`** 로 이 폴더에 둡니다.  
현재는 `2604_Simply.U+설명자료_실천과제.pdf` 를 이 이름으로 복사해 두었습니다.

## 서버 슬롯 등록

관리자·개발 환경에서 `simply-uplus-guideline` id로 **sync-fixed** 를 실행하면 `store` 슬롯에 복사되고, **심플리하게** 4단계 분석 시 이 PDF 요약/발췌가 **최우선** 맥락으로 로드됩니다.

브랜드·VI 가이드라인은 보조 참고이며, Simply U+와 충돌 시 **Simply U+가 우선**입니다.

파일이 없거나 슬롯이 비어 있으면 해당 축은 «미등록»으로 표시됩니다.
